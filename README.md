# Bekaplay Topup Hub

هذا ملف مشروعي "بيكا ستور" (Beka Store). أريدك أن تقرأ الملفات وتفهم المشروع تماماً، وأريد تعديل صفحة تسجيل الدخول وإزالة رسائل الـ SMS نهائياً وتفعيل نظام التحقق المحلي عبر الواتساب (بحيث يولد رمز OTP ويظهر للمستخدم زر يفتح محادثة واتساب مع الإدارة برقم الكود ورقم العميل).
